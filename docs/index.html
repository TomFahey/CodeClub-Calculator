🧮 CodeClub Calculator

Welcome! This project teaches you to build a working touchscreen calculator on the M5Stack Tab5 — a real microcontroller with a big colour screen. By the end you'll have a calculator you built yourself, from scratch, in Python!

Work through the lessons in order. Each one builds on the last.

Session 1

Hello, Screen!

Get started: learn how to make the screen light up, change colours, and display text.

 Session 2

Variables & Buttons

Add a keypad and learn about variables — boxes that store information in your program.

 Session 3

Making it Calculate

Write the maths logic using if/elif — the brain of your calculator.

 Session 4

Finishing Touches

Put it all together, add a clear button, and try some stretch challenges.

Built with MicroPython & UIFlow2 on the M5Stack Tab5.
