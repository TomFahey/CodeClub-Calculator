🖥️ Session 1: Hello, Screen!

Today you are going to make something appear on a real screen — a touchscreen tablet that you can hold in your hands. By the end of this session, your calculator will draw its screen and show a message. It won't do sums yet, but it will look like a proper calculator. Let's go!

New Ideas This Session

📦 import
Imagine a toolbox in another room. import is how you carry those tools into your workspace so you can use them.

Somebody else has already written all the complicated code that draws the screen and handles the buttons. It lives in a file called calculator_ui. With import, we borrow those tools for our program.

⚙️ Calling a function
A function is like a button on a microwave. You press "Start" and it does the job — you don't need to know how the microwave works inside.

In Python, you call a function by writing its name followed by (). We'll use three functions today: setup_screen(), show_result(), and run().

🔤 Strings
A string is a piece of text wrapped in speech marks — like a note you pass to a function.

Whenever you want to give a function some text, wrap it in speech marks: "Hello!". The speech marks tell Python "this is text, not a command".

Step-by-Step

  1. Open main.py in the UIFlow2 editor on your computer. You should see a mostly empty file. That's fine — you're about to fill it!
  2. Type the import line. This goes right at the top of the file. 
    from calculator_ui import setup_screen, show_input, show_result, when_key_pressed, run

    This one line borrows five tools from the calculator_ui helper file: each tool is a function you'll use to control the calculator screen.

    💡 Hint — what does from ... import mean?

    from calculator_ui means "go to the file called calculator_ui".
    import setup_screen, ... means "bring these specific tools into my program".
    After this line, you can use setup_screen() directly — no need to write calculator_ui.setup_screen() every time.

  3. Call setup_screen(). Add this line next: 
    setup_screen()

    This draws the calculator screen — the two display boxes at the top and all twenty keys below. It only needs to be called once, right at the start.

  4. Show a welcome message. Add this line: 
    show_result("Hello!")

    show_result() puts text or a number into the big result box on screen. The text "Hello!" goes inside the brackets, wrapped in speech marks.

    💡 Hint — what if I forget the speech marks?

    Without speech marks Python thinks Hello! is a variable name, and it will show an error because no variable called Hello! exists. Always wrap text in " " to make it a string.

  5. Add run() at the very end. 
    run()

    run() keeps the screen alive. Without it, the program would finish in a blink and the screen would go blank. Always make this the last line.

Your complete main.py should now look like this:

from calculator_ui import setup_screen, show_input, show_result, when_key_pressed, run

setup_screen()

show_result("Hello!")

run()
▶️ Try It!

Make sure calculator_ui.py is already on your Tab5 (your teacher will have set this up). Then press Run in the editor.

You should see the calculator screen appear on the tablet — with all its keys and the message Hello! in the result display.

Try pressing some of the keys. Nothing happens yet — that's coming in Session 2! 🎉

🌟 Challenge

Can you change the welcome message to say your name instead of "Hello!"?

What happens if you call show_result() twice, with different messages? Which one appears on screen? Why do you think that is?
