Session 1: Hello, Screen!

In this session you will write your very first Python program and make the calculator screen show a message.

🧰 New idea: import
Think of a toolbox. Someone else has already built some really useful tools — setup_screen, show_result, and friends. We didn't write them, but we can borrow them. The word import is how we open that toolbox and take out the tools we need.

Type this line at the very top of your program to borrow the calculator tools:

from calculator_ui import setup_screen, show_input, show_result, when_key_pressed, run

calculator_ui is the name of the toolbox.
Everything after import is the list of tools we want to take out.

🔘 New idea: calling a function
Imagine a machine with buttons. Each button makes something happen. setup_screen() is like pressing the "start up the screen" button — the brackets () mean "go and do this job right now".

Add this line to set up the calculator screen:

setup_screen()

Next, tell the screen what to show. We pass a message inside the brackets:

show_result("Hello!")

The text between the quote marks is called a string. You can put any words you like in there.

▶️ New idea: run()
Think of it like pressing Play on a video. Until you press Play, nothing moves. run() starts the calculator and keeps the screen alive so you can see it and tap the buttons.

Always put run() as the very last line of your program. Any code you write after run() will never be reached.

run()

Your full program for Session 1

Put it all together. Your program should look exactly like this:

from calculator_ui import setup_screen, show_input, show_result, when_key_pressed, run

setup_screen()
show_result("Hello!")
run()

Step by step

  1. Open your program in the UIFlow2 IDE.
  2. Type the from calculator_ui import … line at the very top.
  3. On a new line, type setup_screen().
  4. On the next line, type show_result("Hello!").
  5. On the very last line, type run().
  6. Press the Run button. You should see the calculator screen appear with Hello! on it.

🎮 Try it!

Change "Hello!" to your name. Press Run again. What do you see on the screen?

💡 Hint

Just swap the text inside the quote marks: show_result("Ada") — use your own name!

⭐ Challenge

Can you make the screen show your favourite number instead of a word?

💡 Hint

Try show_result(7) — numbers don't need quote marks!
