Session 4: Finishing Touches

You have a working calculator — brilliant! This session you'll add the last three buttons: C (clear), DEL (delete the last digit), and +/− (flip the sign). You'll also get the chance to write a brand-new function yourself as a stretch goal.

📏 New idea: len()
Think of a ruler measuring a word. len("hello") counts the letters and gives you 5. len("") is 0 — an empty string has no characters at all.

We use len(current_input) in press_delete to check there is actually something to delete before we try to remove it.

✂️ New idea: string slicing
Think of tearing letters off a paper strip.
  • "hello"[:-1] tears off the last letter → "hell"
  • "hello"[1:] tears off the first letter → "ello"
  • "hello"[0] reads just the first letter → "h"

The numbers inside the square brackets are called a slice. [:-1] means "from the start, up to but not including the last character".

Function 1: press_clear

This resets everything back to the way it was at the start — like a fresh calculator.

def press_clear():
    global current_input, first_number, operator, start_new_number
    current_input    = ""
    first_number     = 0
    operator         = ""
    start_new_number = False
    show_input("")
    show_result("0")

Every variable is returned to its starting value, and the screen is cleared to show 0.

Function 2: press_delete

This removes the last character the user typed — handy if you press the wrong digit.

def press_delete():
    global current_input
    if len(current_input) > 0:
        current_input = current_input[:-1]
    show_input(current_input)
  • len(current_input) > 0 — only delete if there is something there.
  • current_input[:-1] — take everything except the last character.

Function 3: press_negate

This flips the sign of the current number: positive becomes negative, negative becomes positive.

def press_negate():
    global current_input
    if current_input == "" or current_input == "0":
        return
    if current_input[0] == "-":
        current_input = current_input[1:]
    else:
        current_input = "-" + current_input
    show_input(current_input)
  • If there's nothing to negate, return exits early.
  • current_input[0] == "-" checks if the number is already negative.
  • If it is, current_input[1:] removes the leading minus sign.
  • If it isn't, we stick "-" on the front with "-" + current_input.
